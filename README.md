# خُطى — خطوات صغيرة لأهداف كبيرة

منظم يومي شخصي (PWA عربي يعمل بدون إنترنت): أوراد متكررة تولّد قائمة يومك تلقائيًا، وكل إنجاز يُعدّ رقميًا نحو أهداف الفترة (نصف سنة / سنة).

## المزايا
- **شاشة اليوم مرتّبة على أوقاتك**: فترات مرتبطة بالصلوات (الفجر، الضحى، الظهر، العصر، المغرب، العشاء، قبل النوم) بأوقات تقريبية تعدّلها من الإعدادات. الفترة التي أنت فيها تُفتح وحدها وعليها وسم «الآن»، والبقية مطوية بسطر واحد.
- **أهداف رقمية** لكل فترة (أوجه، صفحات، قصائد، كتب…) مع مؤشر «هل أنت على المسار؟»
- **أوراد متكررة**: يومية، أيام محددة، أو مرنة (N مرات بالأسبوع) — مع فترة اليوم وساعة اختيارية (٣:٠٠ للنادي)
- **سياسة تعويض لكل ورد**: قضاء يلاحق / معايرة وتيرة / عفو
- **جلسة أسبوعية موجهة**: ملخص، فوائت، مراجعة، معايرة، مهام
- **مراجعات شهرية** تُحفظ كسجل تأملات
- **إحصائيات**: تقدم، التزام، توازن مجالات، منحنى أسابيع
- تاريخ **ميلادي + هجري** (أم القرى) · **بياناتك محلية 100%** مع تصدير/استيراد JSON

## التشغيل محليًا
```
npx -y http-server . -p 4173
```

## التثبيت على الجوال
افتح رابط التطبيق في Chrome أو Samsung Internet ← القائمة ← «إضافة إلى الشاشة الرئيسية».

## البنية
HTML/CSS/JS خام بدون build step. `js/engine.js` هو قلب المنطق (توليد اليوميات، التعويض، التقدم)، و`js/dayparts.js` مسؤول عن فترات اليوم وترتيبها. التخزين في `localStorage`. أدوات التوليد في `tools/` (أيقونات وخطوط).

> عند إضافة أي ملف JS جديد: أضِفه إلى `ASSETS` في `sw.js` وارفع `VERSION`، وإلا لن يصل التحديث للأجهزة المثبِّتة.
